Changes

What changed

Provider defaults

Codex App Server is now the default model provider in backend config, settings registry, resolver fallback chain, Settings UI defaults, and docs. Default model value is gpt-5.4.

Azure OpenAI compatibility

Azure OpenAI remains supported. New regression test added to preserve azure_openai when loading existing Azure-backed settings and saving unrelated fields.

Setup and operator surfaces

Jenkins bridge readiness made first-class visible in setup status, /api/settings, settings checklist, and Control Center provider/policy views. Dark operator surfaces were softened to remove harsh dividers while preserving density.

Admin UX fixes

Admin access copy spacing and X-Admin-Key / VITE_ENTRA_* text spacing were corrected.
