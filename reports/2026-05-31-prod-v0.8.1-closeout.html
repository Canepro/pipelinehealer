Prod secrets are injected from Infisical Values redacted

Infisical CLI was upgraded from 0.43.85 to 0.43.89. Production values were staged in project 70ae1697-055c-4fc1-ba90-85b25f6bf138, environment prod, path /pipelinehealer/prod. The deployment used infisical run so values were injected into child processes without printing or committing them.

The prod deploy consumed 32 Infisical-provided names. Sensitive runtime values are referenced in ACA as secret refs, including API/admin keys, GitHub tokens, webhook secrets, audit salt, settings encryption key, and the Codex App Server WebSocket bearer token.

Residual notes

What remains

  • Cloudflare records are DNS-only so Azure managed certificate validation and direct ACA host routing stay simple. Proxying can be revisited later with the usual header and TLS checks.
  • Agent handoff is enabled with copy_only mode. OpenClaw and Hermes need concrete callback/webhook endpoints before PipelineHealer can dispatch them automatically.
  • The frontend runtime config uses the server-side frontend proxy path. If browser-direct API calls are desired later, set VITE_API_URL=https://api.pipelinehealer.canepro.me during frontend build/runtime configuration.
